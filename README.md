# Nail Artistry - Landing Page

Landing page לקורס ציפורניים של ניקול איליבסקי.

## 🏗️ Tech Stack

- **Next.js 14+** - React framework
- **Tailwind CSS** - Styling
- **Lucide React** - Icons
- **RTL Support** - עברית

## 📋 מבנה הדף

- **Header** - ניווט fixed + כפתור התחלה
- **Hero** - סיפור השראה + תמונה placeholder
- **Story** - הסיפור המלא של ניקול
- **Why** - למה הקורס שלי (3 עמודות)
- **FAQ** - 4 שאלות נפוצות (Accordion)
- **CTA** - טופס רישום לקורס
- **Footer** - יצירת קשר וניווט

## 🚀 פיתוח מקומי

```bash
npm install
npm run dev
```

פתח `http://localhost:3000` בדפדפן.

## 📦 פקודות

- `npm run dev` - הרץ development server
- `npm run build` - בנה לפרודקשן
- `npm start` - הרץ production server
